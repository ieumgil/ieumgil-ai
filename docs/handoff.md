# claude.ai 기획 대화 인수인계 (2026-11-10)

claude.ai에서 진행한 기획 대화를 여기서 끝내고 이후 작업은 이 저장소와 Claude Code에서만 한다. 이 문서는 그 대화에서 정한 것과 남은 일을 정리한다.

이후 기획·디자인의 기준은 **이 저장소의 파일**이다. claude.ai 문서는 더 이상 갱신하지 않는다.

## 확정된 것 (요약)

자세한 규칙은 `CLAUDE.md`, 전체 기획은 `docs/planning.md`.

- 대상: 휠체어 / 보행 불편 고령자 / 유모차. 영동권(강릉·속초·동해) 유명 관광지 후보 목록.
- 입력: 시작 → 언제·어디서 → 누구와 → 꼭 필요한 조건 → 좋아하는 곳. 당일~2박 3일.
- AI가 판단·계획하고, 코드는 '불가' 데이터와 계산만 강제한다(11/10 변경, `docs/ai-plan.md`). access 값은 가능/부분가능/불가 중 하나, `미확인`이면 빌드 실패.
- 카카오 길찾기 결과는 저장하지 않는다. 공유 링크에는 장소와 날짜별 순서만.
- 지도 경로는 "일반 차량 경로"로 표기. 휠체어 안전 경로를 보장하지 않는다.
- 개인정보(이름·연락처·IP) 수집 안 함. Gemini 무료 등급에는 개인정보를 보내지 않는다.
- 디자인 토큰은 `src/app/globals.css`의 @theme. 본문 16px 이상, 터치 44px 이상, "가 글씨 크게" 버튼.

## 열린 결정

1. ~~AI 활용 범위~~ → **확정: `docs/ai-plan.md`** (2026-11-10, ① 판단 엔진 · ② 일정 설계 루프 · ③ AI 추가 질문). CLAUDE.md 원칙 1번과 `docs/planning.md`에 반영함.
2. 기획 문서에 답이 없는 질문 3개
   - 과제명 확정
   - 하루 최대 5곳이 맞는지
   - 유형별 여유시간 20~30%가 맞는지 (휠체어 승하차 여유시간 값은 조사·테스트로 결정)
3. 공유 이미지 개선: 지금 시안은 지도·사진이 없어 쓸모가 약하다. 장소 좌표로 직접 그린 간단한 지도 + 사진 썸네일을 넣는 방향을 검토 중.
4. 모션: 나중에 넣는다. 넣을 때 `prefers-reduced-motion`을 지원한다.
