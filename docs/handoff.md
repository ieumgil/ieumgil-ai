## 확정된 것 (요약)

자세한 규칙은 `CLAUDE.md`, 전체 기획은 `docs/planning.md`.

- 대상: 휠체어 / 보행 불편 고령자 / 유모차. 영동권(강릉·속초·동해) 관광지·문화시설. 1차 출처는 관광공사 무장애 여행정보 API(182곳 → 관광지 152곳)(`docs/data/tour-api-fields.md`).
- 입력: 시작 → 언제·어디서 → 누구와 → 꼭 필요한 조건 → 좋아하는 곳. 당일~2박 3일.
- LLM이 읽고·판단하고·계획하고·풀어준다. 코드는 계산과 검사만 강제한다(11/10, `docs/ai-plan.md` v3).
- access 값은 가능/부분가능/불가/모름. '모름'은 숨기지 않고 질문 + 공식 전화번호를 붙인다. '모름'은 판단을 막지 않고 질문으로 붙인다(11/10 개정, 휠체어 진입 원문 없음은 확인 필요). 화면은 '적합 · 전화로 확인할 것 있음'처럼 함께 표시.
- 카카오 길찾기 결과는 저장하지 않는다. 공유 링크에는 안 JSON(장소·순서·체류·이유)만, 시각·경로는 열 때 다시 계산.
- 지도 경로는 "일반 차량 경로"로 표기. 휠체어 안전 경로를 보장하지 않는다.
- 개인정보(이름·연락처·IP) 수집 안 함. Gemini 무료 등급에는 개인정보를 보내지 않는다.
- 디자인 토큰은 `src/app/globals.css`의 @theme. 본문 16px 이상, 터치 44px 이상. 글자 크기는 rem이라 휴대폰·브라우저 설정을 따른다('가 글씨 크게' 버튼은 11/11에 뺐다).
