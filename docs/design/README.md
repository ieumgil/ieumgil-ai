# 디자인 시안 v2 원본

- 온라인 캔버스(참고용, 갱신 중단. 기준은 이 폴더): https://claude.ai/artifact/S2A6vTW33w69QtFQssuoTu
- 이 폴더의 `.dc.html` 파일은 위 캔버스의 화면별 원본이다. 일반 HTML에 템플릿 문법(`{{값}}`, `<sc-for>`, `<sc-if>`)이 섞인 형식이라
  브라우저에서 바로 열리지 않는다. 화면 구조, 문구, 색, 간격을 참고하는 용도로 읽는다.

| 파일 | 화면 |
|---|---|
| Main.dc.html | 시작 화면 |
| When.dc.html | 1단계 언제·어디서(달력, 이동수단, 숙소) |
| Who.dc.html | 2단계 누구와 |
| Conditions.dc.html | 3단계 꼭 필요한 조건 |
| Taste.dc.html | 4단계 좋아하는 곳 |
| ResultMobile.dc.html | 결과(모바일) |
| ResultDesktop.dc.html | 결과(PC) |
| ShareCard.dc.html | 공유 이미지(개선 예정: 지도 그림·사진 썸네일 추가) |

예시 화면의 관광지 이름은 [관광지 A] 같은 자리표시자이고, 시간·거리·문구는 형식 예시다.
